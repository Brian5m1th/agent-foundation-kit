# PM Release Notes & GTM Enablement Skill

> Purpose: Translate technical code releases into user-facing value, draft Release Notes, construct GTM enablement packages, and verify launch readiness.

## Workflow

1. **Feature Delta & Release Scope Analysis**:
   - Ingest PRs, git commit log, or completed Jira/Linear tickets for the release version.
   - Categorize changes into: **New Features**, **Improvements**, **Bug Fixes**, **Breaking Changes / Deprecations**.

2. **Audience-Specific Communication Drafting**:
   - **External Customer Release Notes**: Highlighting user benefits, UI screenshots/GIF placeholders, and action steps.
   - **Internal Changelog (Engineering/Product)**: Technical delta, API changes, migration scripts, roll-back procedure.
   - **Sales & Customer Success (CS) Enablement**: Value proposition, FAQs, objection handling, pricing/tier impact.

3. **Go-To-Market (GTM) Collateral**:
   - In-app notification copy & modal announcement text.
   - Product Marketing blog post outline & email newsletter blurb.

4. **Pre-Launch & Rollout Checklist**:
   - Feature flag status (Canary / Staged Rollout percentage).
   - CS/Support team briefing completed.
   - Documentation & Help Center articles updated.
   - Telemetry verification & error dashboard monitoring plan.

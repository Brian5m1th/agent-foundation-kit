# PM Strategy & Prioritization Framework Skill

> Purpose: Evaluate candidate product initiatives, calculate quantitative prioritization scores (RICE/ICE), perform competitive teardowns, and generate defensible roadmaps.

## Workflow

1. **Initiative Scope & Objectives**:
   - Ingest list of feature candidates, strategic bets, or roadmap requests.
   - Map each initiative to company OKRs and product vision.

2. **RICE / ICE Quantitative Scoring**:
   - **RICE Score**: `(Reach × Impact × Confidence) / Effort`
     - *Reach*: Number of users impacted per quarter.
     - *Impact*: 3 = Massive, 2 = High, 1 = Medium, 0.5 = Low, 0.25 = Minimal.
     - *Confidence*: 100% = High data proof, 80% = Medium, 50% = Low/Guesstimate.
     - *Effort*: Person-months required across Product, Design, Engineering.
   - **ICE Score**: `Impact × Confidence × Ease` (scored 1-10 each).

3. **Kano Model Classification**:
   - Categorize features into:
     - **Basic/Must-have**: Absence causes dissatisfaction.
     - **Performance/One-dimensional**: Satisfaction increases linearly with execution.
     - **Delighters/Attractive**: Unexpected features that create high excitement.

4. **Competitive Teardown & Positioning**:
   - Analyze competitor approaches to the same problem.
   - Identify differentiation opportunities (Moat, Unique Value Proposition).

5. **Prioritized Roadmap Recommendation**:
   - Deliver ranked initiatives table with clear scoring justifications and quarter/sprint allocations (Now, Next, Later).

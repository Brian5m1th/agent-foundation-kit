# Screenshot & Mockup Prototype Skill

> Purpose: Translate visual mockups, screenshots, or Figma designs into clean, responsive HTML/CSS/JS or React components with high fidelity.

## Workflow

1. **Visual Analysis**:
   - Inspect screenshot/mockup for layout grid, colors, typography hierarchy, icon style, and interactive components.
   - Identify design token candidates (colors, fonts, radii).

2. **Component Anatomy Breakdown**:
   - Deconstruct page into modular components (Header, Sidebar, Hero, Card Grid, Modal, Footer).
   - Ensure responsive layout adaptation for mobile viewports.

3. **High-Fidelity Implementation**:
   - Write clean, semantic HTML5 structure.
   - Apply CSS variables and design system tokens.
   - Implement interactive states (hover, active, focus, disabled).

4. **Visual Parity Verification**:
   - Capture screenshot of rendered code and compare against target mockup.
   - Refine pixel alignment, font weights, and spacing gaps.

# Plan Skill (Planning Mode)

When activated, you MUST enter **Planning Mode**:

1. **Research & Think**: Use read-only tools (`view_file`, `grep_search`, `list_dir`) and `sequential-thinking` to inspect the project. Do not modify any code.
2. **Draft Plan**: Create `implementation_plan.md` outlining the problem, architectural changes, proposed file edits, and verification steps.
3. **Stop & Wait**: Present the plan to the user and await explicit approval before starting implementation.
